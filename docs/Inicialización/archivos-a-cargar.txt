La configuración del servidor se hace en caliente por este backend cada vez que se inicializa un nuevo server, 
por eso no hay que tocar los archivos de server.cfg, por ejemplo.

Lo que sí hay que tocar son los archivos de admins, en:
    game/csgo/addons/counterstrikesharp/configs/admins.json
        {
            "[ADMIN]Falso": {
                "identity": "06561198252109564",    → STEAMID64
                "immunity": 100,                    → Un admin de inmunity 100 no puede aplicar comandos sobre uno de inmunity 110, por ejemplo.
                "flags": [
                "@css/root"                         → Se pueden crear "tiers" de admins, no implementado por ahora.
                ]
            },
            "[Admin]Igna": {
                "identity": "STEAMID64",
                "immunity": 100,
                "flags": [
                "@css/root"
                ]
            }
        }

    game/csgo/cfg/MatchZy/admins.json
        {
        "06561198252109564": "",    → El "falso" que está arriba.
        "STEAMID64": ""             → Dejar vacío, el nombre se pone en el admins.json de css
        }
